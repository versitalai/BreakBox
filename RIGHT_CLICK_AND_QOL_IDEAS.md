# 🖱️ Right-Click & Quality-of-Life Ideas

Brainstorm only — nothing here is scheduled or implemented yet. Right-click is
currently unused in the editor (`_disableCtrlContextMenu` in
`editor/widgets/SongEditor.ts` just suppresses the browser's native menu), so
this is a clean slate.

Organized by walking through the song-making workflow start to finish, since
that surfaces which actions are repetitive enough to deserve a shortcut.
Related ideas are grouped together at the end.

## Backlog (already scoped, not started)

1. **Keybind settings** — a UI to remap keyboard shortcuts.
2. **Relative multi-instrument modulation** — shift-click multiple instrument
   patterns, adjust a shared control (volume, pan, EQ, etc.), and each
   instrument shifts by the same delta instead of snapping to one value.
3. **Context-sensitive right-click menu** — three menus depending on target:
   - **On a note:** per-note controls — pitch lock (restrain slide notes),
     duration lock (restrain length), and others below.
   - **On a pattern:** quick pattern settings — tempo quick-edit, beats-per-
     measure quick-edit with a global/local toggle, and others below.
   - **On empty canvas / general screen:** app-level controls — theme, UI
     settings, and others below.
4. **Manual keyframes on notes** — right-click a note (ties into item 3) to
   add keyframes by hand, shown visually, instead of only the ones
   auto-generated by volume/slide changes.

## Starting a song

- **Right-click empty canvas → app menu.** Theme, UI density, keybind
  settings (item 1), preferences — one place instead of hunting through top
  menus.
- **Recent/template songs.** A "start from" menu: last N songs edited
  locally, or a few starter templates (empty 4-channel kit, empty breakcore
  kit, etc.) — cuts the blank-page setup tax.
- **Tempo/scale/key as a one-shot startup prompt**, optional, so the song's
  bones get set before touching a single note instead of hunting three
  separate menus later.

## Adding channels & instruments

- **Right-click a channel header → channel menu.** Duplicate channel (with
  or without patterns), mute/solo others, color, rename — constant actions
  while building a kit that currently need dedicated buttons/scrolling.
- **Right-click an instrument slot → instrument menu.** Duplicate
  instrument, copy/paste instrument settings (exists as buttons already —
  right-click makes it one motion instead of two), quick preset swap
  without opening the full dropdown.
- Channel-level and instrument-level right-click menus belong together as
  one "structural" context-menu family, separate from per-note and
  per-pattern menus (see Cross-cutting groupings below).

## Placing notes (the composing loop)

The most repetitive right-clicking happens here, so it's worth the most
menu real estate:
- **Per-note menu (item 4's home):** pitch lock, duration lock, manual
  keyframes, delete, and also:
  - **Quick probability/roll-count** — a right-click number-entry is faster
    than dragging for precise values.
  - **Nudge pitch by octave** — one click instead of drag-across-many-semitones.
  - **Set as chord root / convert to chord**, if chord tooling exists.
- **Multi-note selection + right-click** should apply anything above to the
  whole selection — the single highest-leverage QoL item in this group,
  since composing breakcore fills means placing/adjusting many notes at
  once, not one at a time.

## Editing patterns

- **Right-click pattern → pattern menu** (already scoped in item 3): tempo
  quick-edit, beats-per-measure with global/local toggle, plus:
  - **Duplicate pattern to next bar** — one click instead of copy, click
    bar, paste.
  - **Reverse pattern / humanize pattern**, if those exist as global tools —
    exposing them per-pattern saves a trip to a prompt dialog.
  - **Pattern color tag** for visual scanning in long arrangements.

## Arranging (the bar/track grid)

- **Right-click a bar in the track view → bar menu.** Insert/delete bar at
  this position, duplicate bar across all channels at once (not just one
  channel's pattern) — "do this to every channel at this bar" comes up
  constantly and today likely means repeating the action per channel.
- **Drag-select a bar range → bulk operations** (delete range, duplicate
  range), grouped with the above since it's the same mental action at a
  bigger scale.

## Mixing & effects

- **Item 2 (relative multi-instrument modulation)** belongs here — the
  mixing-stage equivalent of multi-select-and-edit that notes get in the
  composing stage. Worth building both with the same underlying "relative
  delta" logic rather than two separate implementations.
- **Right-click an effect knob → numeric entry + reset to default.**
  Fine-tuning EQ/pan/gain by drag is imprecise; a right-click number box
  next to "reset" is a small, high-frequency win.

## Sharing & exporting

Not requested yet, but sits naturally at the end of the workflow:
- **Right-click the export/copy-URL button** for quick variants (copy JSON,
  copy URL, download WAV) instead of a full prompt every time. Only worth
  doing once the main menus above exist; listed here for completeness.

## Cross-cutting groupings

- **"Structural" menus** (channel, instrument, bar) — all duplicate/delete/
  color-tag flavored. Could share one context-menu component.
- **"Value editing" menus** (note properties, pattern quick-edit, effect
  knobs) — all numeric-entry-plus-reset flavored. Could share another
  shared component.
- **"Selection-aware" behavior** (multi-note edit, multi-instrument
  relative modulation, bar-range bulk ops) — the biggest actual workflow
  win, and worth designing as one selection→apply-delta system used
  everywhere instead of three bespoke features.
